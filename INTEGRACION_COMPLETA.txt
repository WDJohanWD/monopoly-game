🔄 FLUJO INTEGRADO
═══════════════════════════════════════════════════════════════════════════════

Usuario
   ↓
Board.tsx (renderiza GameContainer)
   ↓
GameContainer (carga API, orquesta juego)
   ↓
MonopolyBoard + DiceRoller + Controles (muestran UI)
   ↓
Usuario interactúa (clic en botones)
   ↓
API Calls (rollDice, buyProperty, endTurn)
   ↓
Backend valida y procesa
   ↓
Respuesta sincroniza estado
   ↓
UI se actualiza con animaciones
   ↓
Repite ciclo


🎮 DEMOSTRACIÓN RÁPIDA
═══════════════════════════════════════════════════════════════════════════════

1. Crea un juego:
   curl -X POST http://localhost:5093/api/game \
     -H "Content-Type: application/json" \
     -d '{"players": [...], "startingMoney": 1500}'

2. Copia el ID del juego

3. Navega a:
   http://localhost:5173/board/{game-id}

4. ¡Diviértete! 🎉
